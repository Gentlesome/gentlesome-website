# Gentlesome Website

This repository contains the static website files for the `Gentlesome` brand site.

## Files

- `index.html`: homepage
- `styles.css`: homepage styles
- `script.js`: homepage interactions
- `login.html`: personal space login page
- `login.css`: login page styles

## Upload To GitHub

1. Create a new repository on GitHub.
2. Upload all files in this folder to the repository root.
3. If you want a public website, enable GitHub Pages:
   - Open `Settings`
   - Open `Pages`
   - Under `Build and deployment`, choose `Deploy from a branch`
   - Select the `main` branch and the `/root` folder
4. Save the settings and wait for GitHub Pages to publish.

## Update Later

When the site is changed later, you do not need to rebuild everything from scratch.
You only need to replace or push the files that changed.

If you use the GitHub website:

1. Open the repository
2. Replace the changed files
3. Commit the changes

If you use Git locally:

1. Save the updated files
2. Run `git add .`
3. Run `git commit -m "Update website"`
4. Run `git push`

GitHub Pages will then update the website automatically.
